# Lucky 同声翻译 · 网页版

面向手机的双向语音翻译和英语口语练习工具。进入后可选择 `English Coach` 或 `Translator`。翻译器上下共用 `LanguagePanel`。默认面对面布局将上半屏旋转 180°；设置中的单人布局让账户持有者在底部操作 Listening / Speaking。你使用蓝色内框，对方使用绿色内框。面对面布局的切换按钮交换双方位置，语言、译文和颜色一起移动。每一侧可以选择语言；选中另一侧当前语言时自动交换，始终保持两种不同语言。

网站入口由服务器密码保护。验证成功后使用仅限该站点的安全 Cookie 在当前设备保持登录 30 天；设置中可以立即锁定。生产密码作为 Sites 服务器密钥保存，不写入网页源码。

- 面对面布局的上下两侧各有一个共用录音状态的大按钮。大按钮长按录音，松开提交尾句并关闭麦克风；快速双击保持录音，再点一次停止。
- 按住模式不会在说话或停顿中途分段，只在松手时提交。双击持续模式在静音满 5 秒或本机检测到明显的说话人声音变化时分段，联网识别和翻译时继续收音。将识别到的任意语言或混合语言转成双方所选语言。
- 单人布局把录音控制集中到底部。Listening 和 Speaking 本身就是两个录音按钮：点击开始持续录音，再点停止；长按则松手停止。Listening 固定从对方语言翻译到自己的语言，Speaking 固定从自己的语言翻译到对方语言；两种方向都在完成后播放目标语言。
- English Coach 使用英语进行自然对话，遵循本机 `english-conversation-coach` 技能的训练规则，结合用户实际话题和历史记忆逐步调整难度；有用的新表达会在回复中少量加粗。结束对话会先生成当天的学习总结，再可基于本次内容生成六道练习：两道关键词填空（首字母和英文释义提示）、两道词义三选一、两道语法三选一。
- Coach 对话页的 Lucky 猫猫固定在上方、对话在下方。猫猫复用桌面宠物的待机、梳毛、擦脸、眨眼、摇尾、轻拍、抗议、说话、入睡、翻肚皮和唤醒动作；清醒时每点一次随机做一种动作，睡着后前两次点击切换睡姿，第三次点击唤醒。朗读、收音和思考时会自动切换对应动画。
- 猫猫坐在橄榄绿色地毯的家居场景中。网页按设备当地时间在 07:00–19:00 使用阳光清晨背景，其余时间使用冷色温馨夜景；两张压缩背景合计不到 90KB。全部宠物动作按需加载，不包含约 700MB 的 Electron 桌面运行环境。
- 个人中心记录本设备今日练习时长、今日总结、每日总结和每周总结。每日 Recall 用表格保存重点英文词汇与英文释义，以及语法点与英文例句；可能由转写造成的问题只标记为“可能”。进入新的一周并生成新总结时，上一周每日记录会先合并为周总结，合并成功后才删除该周的每日明细。每日和每周记录都可导出 TXT。
- 录音识别完成后，原话先完整出现在说话方内框；另一侧同一位置显示“正在翻译…”，收到译文后再替换为正式内容。页面中间不再重复显示翻译进度。
- 内框保留本次页面中的全部对话。说话人以小字放在内容同一行，旧句使用较小文字，最新一句使用大字；可滑动、滚轮、键盘或通过框内上下箭头翻页。阅读旧内容时不强制跳回新句。交换双方位置后按对应语言保留记录。
- 自己这一侧可打开正向竖排的完整对话，按时间顺序阅读，并复制全部或导出带原文、双方译文的 UTF-8 TXT；不会因超过 50 句丢失早期内容。
- 点击上下任意一句文字会打开统一修改窗口；手机上使用单句全屏编辑，避免软键盘挤压对话界面。保存后结合该句之前的上下文重新翻译，并替换原句。
- 对方固定显示 `other speaks`；自己默认显示 `Me`。首次可填写名字，保存在本机浏览器，下次自动使用；设置中可修改。
- 每一句开头都有朗读按钮。正文可点击打开修改窗口；手机长按正文使用系统原生选词，可拖动首尾、复制或全选。长按录音完成翻译后自动用对方语言播放；语速可设为 0.75×、1×、1.5× 或 2×。录音时禁用朗读避免回声重复翻译。
- 你的区域显示本次实际 Token 和费用，金额精确到 $0.01。显示倍率默认 1.0，可在设置中调整并保存到本设备；显示金额等于按官方单价计算的实际费用乘以倍率。清空对话同时清空本次用量。
- 支持主屏幕快捷方式、独立窗口、应用图标和离线提示。翻译必须联网。

## 运行与服务

`npm install`，`npm run dev`；生产构建 `npm run build`。Sites 配置在 `.openai/hosting.json`，复用其中的项目，不要重复创建。

首次在页面的设置中填写自己的 OpenAI 或 DeepSeek API 密钥并选择文字翻译引擎。密钥保存在该客户当前设备、当前浏览器的本地存储中，下次打开自动恢复；可在设置中随时清除。录音识别、AI 朗读和自定义声音需要 OpenAI 密钥；DeepSeek 当前只负责文字理解与翻译，不提供声音训练接口。每名访问者使用自己的密钥和额度。本版本没有运营方统一供给的翻译额度；若要让访客免填密钥，需要另行配置统一服务及访问/费用控制。

语言偏好、页面布局、双方位置、自定名字、语速和客户自己的 API 密钥存入当前设备的浏览器。音频在浏览器中分句，由当前设备直接请求 OpenAI 识别，再直接请求所选服务商翻译；AI 朗读也由当前设备直接请求 OpenAI。网页服务器不转发密钥、录音或对话。应用不持久化录音和译文，供应商的数据处理以其政策为准。Service Worker 不缓存接口、密钥或录音。

语音识别优先使用 `gpt-4o-mini-transcribe`，模型停用/不可用时尝试 `whisper-1`，不强制输入语言。OpenAI 翻译依次使用轻量候选 `gpt-4o-mini`、`gpt-4.1-nano`、`gpt-5-nano`；English Coach 固定使用 `gpt-4o-mini`；DeepSeek 翻译使用 `deepseek-v4-flash` 并关闭思考模式。只在模型不可用错误时尝试下一个 OpenAI 轻量候选，鉴权、额度、网络错误不触发回退。不会选用 6.0 或自动升级到大型模型。每次携带最近 6 句原话作为上下文（每句最多 1000 字），要求先理解整句意图、习惯表达、省略和语气，再用自然口语表达；只翻译当前句，不回答对话中的问题、不添加未说出的细节。清空对话也清空上下文。返回上下两侧的 JSON 译文。识别、翻译均需要实际服务密钥。没有内置演示译文。

页面密码仍由同源服务器验证；模型请求从访问者的浏览器直接发出。因此供应商看到的是访问设备的网络出口，源码不包含本机代理地址。

## 添加到桌面

- iPhone / iPad：Safari 打开网址 → 分享 → 添加到主屏幕。
- 安卓：Chrome 菜单 → 安装应用 / 添加到主屏幕。
- 电脑：支持 PWA 的浏览器地址栏或菜单 → 安装应用。

浏览器是否提供安装入口由平台决定。麦克风需要 HTTPS（本机 localhost 例外）和授权。页面进入后台、锁屏、断网会停止录音；不会在后台监听。

## 验证与界限

`node --test tests/translation.test.mjs` 检查长按/双击/取消、语言互换、静音过滤、分句与 WAV、授权延迟后的停止、输入校验、双目标翻译数据流、服务错误。服务成功响应使用测试模拟，不能代表实际识别准确率。

`npx tsc --noEmit` 检查类型；`npm run build` 构建 Worker 和客户端。当前未使用真实密钥验证端到端语音质量，也未在实体 iPhone / 安卓上测试麦克风与安装。

这是逐句翻译，包含识别和翻译请求的网络延迟，不是逐字流式同传。持续模式用音量与声音基频变化在本机判断停顿和换人；声音相近、嘈杂、音量过轻或多人重叠时可能漏分或误分。队列最多等待 4 句；积压或失败会明确提示并停止收音。每轮持续录音最多 10 分钟。

接口依据：[OpenAI 语音转写](https://developers.openai.com/api/docs/guides/speech-to-text)、[结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs)。
