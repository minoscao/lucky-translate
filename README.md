# Lucky 同声翻译 · 网页版

面向手机的双向语音翻译工具。上下共用 `LanguagePanel`，上半屏旋转 180°。你使用蓝色内框，对方使用绿色内框。中间工具栏左侧的切换按钮交换双方位置，语言、译文和颜色一起移动。每一侧可以选择语言；选中另一侧当前语言时自动交换，始终保持两种不同语言。

网站入口由服务器密码保护。验证成功后使用仅限该站点的安全 Cookie 在当前设备保持登录 30 天；设置中可以立即锁定。生产密码作为 Sites 服务器密钥保存，不写入网页源码。

- 上下两侧各有一个共用录音状态的大按钮，主要提示跟随本侧语言、第二行显示另一侧语言。大按钮长按录音，松开提交尾句并关闭麦克风；快速双击保持录音，再点一次停止。
- 持续录音在本机按停顿分句，联网识别和翻译时继续收音。将识别到的任意语言或混合语言转成双方所选语言。
- 内框保留本次页面中的全部对话。旧句使用较小文字，最新一句使用大字；可滑动、滚轮、键盘或通过框内上下箭头翻页。阅读旧内容时不强制跳回新句。交换双方位置后按对应语言保留记录。
- 自己这一侧可打开正向竖排的完整对话，按时间顺序阅读，并复制全部或导出带原文、双方译文的 UTF-8 TXT；不会因超过 50 句丢失早期内容。
- 点击上下任意一句文字会打开统一修改窗口；手机上使用单句全屏编辑，避免软键盘挤压对话界面。保存后结合该句之前的上下文重新翻译，并替换原句。
- 对方固定显示 `other speaks`；自己默认显示 `Me`。首次可填写名字，保存在本机浏览器，下次自动使用；设置中可修改。
- 支持文字输入、复制、系统朗读、本次对话记录。录音时禁用朗读避免回声重复翻译。
- 你的区域显示本次实际 Token 和费用，金额精确到 $0.01。显示倍率默认 1.0，可在设置中调整并保存到本设备；显示金额等于按官方单价计算的实际费用乘以倍率。清空对话同时清空本次用量。
- 支持主屏幕快捷方式、独立窗口、应用图标和离线提示。翻译必须联网。

## 运行与服务

`npm install`，`npm run dev`；生产构建 `npm run build`。Sites 配置在 `.openai/hosting.json`，复用其中的项目，不要重复创建。

首次在页面的设置中填写自己的 OpenAI API 密钥。密钥保存在该客户当前设备、当前浏览器的本地存储中，下次打开自动恢复；可在设置中随时清除。密钥不写入源码或 Sites 配置，服务器仅将它转发到固定的 OpenAI 地址且不记录。每名访问者使用自己的密钥和额度。本版本没有运营方统一供给的翻译额度；若要让访客免填密钥，需要另行配置统一服务及访问/费用控制。

语言偏好、双方位置、自定名字和客户自己的 API 密钥存入当前设备的浏览器。音频在浏览器中分句，传入同源 `/api/translate`，然后调用 OpenAI 识别和翻译。应用不持久化录音和译文，服务器不持久化密钥。供应商的数据处理以其政策为准。Service Worker 不缓存接口、密钥或录音。

语音识别优先使用 `gpt-4o-mini-transcribe`，模型停用/不可用时尝试 `whisper-1`，不强制输入语言。翻译依次使用轻量候选 `gpt-4o-mini`、`gpt-4.1-nano`、`gpt-5-nano`；只在模型不可用错误时尝试下一个，鉴权、额度、网络错误不触发回退。不会选用 6.0 或其他大型模型，轻量候选均不可用时停止并提示。每次携带最近 6 句原话作为上下文（每句最多 1000 字），要求先理解整句意图、习惯表达、省略和语气，再用自然口语表达；只翻译当前句，不回答对话中的问题、不添加未说出的细节。清空对话也清空上下文。返回上下两侧的 JSON 译文。识别、翻译均需要实际服务密钥。没有内置演示译文。

本地预览使用同一处理函数的 Node 适配器，支持 Node 的环境代理设置。需要本机代理时，用该代理设置 `HTTPS_PROXY`、`HTTP_PROXY`、`NO_PROXY=localhost,127.0.0.1` 和 `NODE_USE_ENV_PROXY=1` 后运行。线上仍使用 Cloudflare Worker，源码不包含本机代理地址。

## 添加到桌面

- iPhone / iPad：Safari 打开网址 → 分享 → 添加到主屏幕。
- 安卓：Chrome 菜单 → 安装应用 / 添加到主屏幕。
- 电脑：支持 PWA 的浏览器地址栏或菜单 → 安装应用。

浏览器是否提供安装入口由平台决定。麦克风需要 HTTPS（本机 localhost 例外）和授权。页面进入后台、锁屏、断网会停止录音；不会在后台监听。

## 验证与界限

`node --test tests/translation.test.mjs` 检查长按/双击/取消、语言互换、静音过滤、分句与 WAV、授权延迟后的停止、输入校验、双目标翻译数据流、服务错误。服务成功响应使用测试模拟，不能代表实际识别准确率。

`npx tsc --noEmit` 检查类型；`npm run build` 构建 Worker 和客户端。当前未使用真实密钥验证端到端语音质量，也未在实体 iPhone / 安卓上测试麦克风与安装。

这是停顿后逐句翻译，包含识别和翻译请求的网络延迟，不是逐字流式同传。声学分句使用音量门限，在嘈杂环境、过轻音量或多人重叠说话时可能漏分或误分。单句最长约 10 秒，队列最多等待 4 句；积压或失败会明确提示并停止收音。每轮持续录音最多 10 分钟。

接口依据：[OpenAI 语音转写](https://developers.openai.com/api/docs/guides/speech-to-text)、[结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs)。
